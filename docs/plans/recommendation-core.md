# Recommendation core increment

Outcome: a traceable plan of up to three eligible steps for the complete career target, independent of radar focus; honest catalog blockers; separate assessed and estimated progress; grounded tool-using AI coach; assessed competency gaps for HR.

Parallel slices: engine + whole-dataset evaluation; server + coach validation; view/HR pure helpers; UI integration. Each slice owns separate files. Keep the existing visual design and dataset.

Checks: deterministic calculations and history boundaries, filters and prerequisite steps; stale skill/event regression on goal/profile change; all-employee eligibility and coverage; representative relevance review; mocked provider tool loop and failure limits; real browser profile/goal switching and unavailable API state. A mocked provider is not a live model verification, rule validity is not recommendation accuracy.

Known data limitations: synthetic snapshot, no measured learning outcomes or vacancies; catalog gains are estimates. No goal is invented for employees without one. API credentials must be configured server-side before live coach verification.
